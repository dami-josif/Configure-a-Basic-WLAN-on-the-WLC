Packet Tracer - WLAN Configuration

Objectives


Background / Scenario


You will apply your WLAN skills and knowledge by configuring a home wireless router and an enterprise
WLC. You will implement both WPA2-PSK and WPA2-Enterprise security. Finally, you will connect hosts to
each WLAN and verify connectivity.

In this activity, you will configure both a wireless home router and a WLC-based network. You will implement
both WPA2-PSK and WPA2-Enterprise security.
